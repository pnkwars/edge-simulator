# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security reports.

Email the maintainers or open a private security advisory on GitHub. Include steps to reproduce, impact, and a minimal test case if possible.

We aim to acknowledge within 48 hours and to provide a fix or mitigation plan within 7 days.

## Scope

- `app.py` local server, `gamble.py` CLI, and static web UI (`index.html`, `retro.html`).
- This project has no backend, auth, or external API at runtime beyond Tailwind/Chart.js CDNs.

Thanks for helping keep Edge Simulator safe.
